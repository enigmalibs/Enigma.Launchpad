# FEATURE-7298 — New application icon

**Status:** DONE
**Type:** FEATURE
**Branch:** `feature/feature-7298-new-app-icon`
**Run:** feature/2026-10-29-uniform-enigma-apps

## Objective

Replace the application icon with the new set in `C:\Dev\EnigmaLibs\Branding\Apps\final\launchpad`
(`enigma-launchpad.ico`, ten PNG frames, one SVG master) everywhere the repository carries it.

## Context & constraints

- **The new artwork** is LP-A2 (Rocket, the *Soft* palette), generated by the Branding repository's
  `Apps/export.py`. Its `.ico` holds ten 32-bit PNG frames (16, 20, 24, 32, 40, 48, 64, 96, 128, 256), each
  byte for byte the matching `png/enigma-launchpad-N.png` (checked). The current `app.ico` holds seven frames
  (16, 24, 32, 48, 64, 128, 256).
- **Where the icon lives today:**
  - `src/Enigma.Launchpad.Desktop/Assets/app.ico`: the `ApplicationIcon` and `MainWindow.Icon`;
  - `src/Enigma.Launchpad.Desktop/Assets/app-256.png`: the 256 frame as a PNG, which the About dialog will
    show (FEATURE-2961);
  - `packaging/linux/icons/enigma-launchpad-N.png`: installed by `install.sh` into `hicolor/<N>x<N>/apps`
    and removed by `uninstall.sh`, both from their own `ICON_SIZES` list (seven sizes).
- No SVG master is in the repository yet. GitClient keeps its masters in `packaging/icon/`.
- hicolor has `96x96` but no 20 or 40 directory.
- No test pins the application icon today.

## Steps

1. Copy, byte for byte:
   - `enigma-launchpad.ico` → `src/Enigma.Launchpad.Desktop/Assets/app.ico`;
   - `png/enigma-launchpad-256.png` → `src/Enigma.Launchpad.Desktop/Assets/app-256.png`;
   - `enigma-launchpad.svg` → `packaging/icon/enigma-launchpad.svg`;
   - the 16, 24, 32, 48, 64, 96, 128 and 256 PNGs → `packaging/linux/icons/`.
2. `install.sh` and `uninstall.sh`: `ICON_SIZES=(16 24 32 48 64 96 128 256)`. Their header comments and help
   say eight sizes instead of seven.
3. `README.md` and `docs/RELEASE.md`: the installed icon comes in eight sizes. The README's layout table
   gains `packaging/icon`.
4. New `AppIconTests` (Desktop tests, headless), in GitClient's shape:
   - `app.ico` holds ten square 32-bit PNG frames, 16 to 256;
   - `app-256.png` is the icon's largest frame, byte for byte, 256 × 256;
   - every size `install.sh` installs has its PNG, byte for byte the `.ico`'s frame, and `uninstall.sh` lists
     the same sizes.

## Acceptance criteria

- The destinations hold the new files byte for byte; the old seven-frame icon is gone.
- `install.sh` and `uninstall.sh` agree on eight sizes, each with its PNG.
- `AppIconTests` pass, the whole suite is green, and the Release build has zero warnings.

## Out of scope

- The application's own accent colours.
- The 20 and 40 px PNGs as Linux icons (no hicolor directory; they ship inside the `.ico`).
- Copying the icon to the output directory (FEATURE-7F4A).
