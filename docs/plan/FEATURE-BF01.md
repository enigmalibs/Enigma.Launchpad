## Objective

Replace the application icon with the new set in `C:\Dev\EnigmaLibs\Branding\Apps\final2\launchpad`
(`enigma-launchpad.ico`, ten PNG frames, one SVG master). Update every place the repository carries it: the
executable and window icon, the About dialog's image, the Linux installer's icons and the SVG master.

## Context & constraints

- **The new artwork** is the same drawing as FEATURE-7298's (LP-A2, the rocket in the *Soft* palette), **without
  the dark rounded tile**: the background is transparent. The rocket's window, which was a dark disc, is now a hole
  in the body (`fill-rule="evenodd"`), so the background shows through it. Generated by
  `Branding/Apps/export.py final2`, which the SVG's header comment names.
- **The new `.ico`** holds the same ten 32-bit RGBA PNG frames as today (16, 20, 24, 32, 40, 48, 64, 96, 128, 256).
  Each frame is byte for byte the matching `png/enigma-launchpad-N.png` (checked while planning).
- **Where the icon lives** (unchanged since FEATURE-7298 / FEATURE-7F4A / FEATURE-2961):
  - `src/Enigma.Launchpad.Desktop/Assets/app.ico`: the `ApplicationIcon`, `MainWindow.Icon`, and the `app.ico`
    copied beside the executable;
  - `src/Enigma.Launchpad.Desktop/Assets/app-256.png`: the About dialog's image, the `.ico`'s 256 frame byte for
    byte;
  - `packaging/icon/enigma-launchpad.svg`: the master;
  - `packaging/linux/icons/enigma-launchpad-{16,24,32,48,64,96,128,256}.png`: what `install.sh` installs
    (`ICON_SIZES`).
- `AppIconTests` (Desktop tests) pins the frames, the About copy, the Linux copies and the output copy. Desktop tests
  run on this machine.
- The source directory is outside the repository and is left in place.

## Steps

1. Copy, byte for byte:
   - `enigma-launchpad.ico` → `src/Enigma.Launchpad.Desktop/Assets/app.ico`;
   - `png/enigma-launchpad-256.png` → `src/Enigma.Launchpad.Desktop/Assets/app-256.png`;
   - `enigma-launchpad.svg` → `packaging/icon/enigma-launchpad.svg`;
   - the 16, 24, 32, 48, 64, 96, 128 and 256 PNGs → `packaging/linux/icons/`.
2. Check that no current prose describes the icon's dark tile (README, comments, tests). Fix any that does. Past
   release notes stay as they are.
3. Release build, whole suite.
